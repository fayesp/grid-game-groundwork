# 玩家翻滚动画采用物理接地翻滚

玩家移动的翻滚动画是绕支撑面前缘边的物理翻倒：支点 = 位置 + 行进方向×0.5 + forward×0.5（支撑面在 +Z 侧半格处，即朝下落方向贴地的一面），旋转轴 = `Cross(back, Dir)`——上下移动绕 X 轴（上 +X / 下 -X），左右移动绕 Y 轴（左 +Y / 右 -Y）。不存在绕 Z 轴的翻滚：`Dir` 沿 Z 时旋转轴退化为零向量（无法绕行进方向本身翻滚），此时 `DORotate` 不旋转但仍触发 OnComplete 收尾，属安全降级。

## Considered Options

- **屏幕面内翻滚**（旋转轴平行 Z，支点取屏幕平面内的前缘角）：代码曾长期如此（含 2026-10-04 上午一次把该约定"统一化"的修复），实际运行看起来不对，被否决。
- **物理接地翻滚**（本决定）：与 `RollCube.cs` 原型一致的翻倒轨迹，翻滚中段中心沿 -Z 短暂抬起约 0.207。

## Consequences

- 翻滚中段的 -Z 抬起是预期外观，不是 bug。
- `PlayerView.CalculateRollPivot` 与 `Player.CalRollPivot` 必须保持同一份公式，改动需同步。
- `PlayerRollMoveTests` 以"非运动的水平轴恒定 + z 抬升 + 精确落点"锁定该约定（屏幕面内翻滚会使这些测试变红）。
